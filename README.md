# 可悠福利抽奖站

独立的教师节福利抽奖小程序。用户用老师发放的卡密抽奖，后台配置奖品、卡密和领取记录。挂到 Telegram 后，领取记录会带上用户头像、用户名和 ID。

## 安装说明

这是静态站点，不需要安装依赖。

1. 克隆仓库
2. 用本地静态服务打开项目目录，例如：

```bash
python -m http.server 8768
```

用户页：`http://127.0.0.1:8768/`  
后台：`http://127.0.0.1:8768/admin/`

默认后台账号 `admin`，默认密码 `keyou2026`。登录后可在「基础设置」里修改。

## 使用方法

1. 后台配置奖品名称、数量、扇区颜色和「抽后返回奖池」
2. 生成卡密并发给用户
3. 用户验证卡密后转动转盘
4. 领取记录可按卡密、Telegram 用户名或 ID 搜索，也可导出
